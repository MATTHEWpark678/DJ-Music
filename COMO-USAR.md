# Separador de Vozes — pacote novo (v3)

Todos os arquivos estão soltos (sem pastas). Basta enviar todos para o GitHub, substituindo os antigos.

## Atualizar no GitHub (pelo site, no celular)
1. Abra o seu repositório no github.com (pelo navegador, não pelo app).
2. **Add file → Upload files**.
3. Toque na área de envio → menu ≡ → **Downloads** → selecione **todos** os arquivos da pasta extraída do zip (não envie o zip em si).
4. Role até o fim e toque em **Commit changes**. Em 1–2 minutos o site atualiza.
5. Abra o app, feche e abra de novo uma vez (para carregar a versão nova).

## Primeiro uso
1. Aba **Ajustes** → escolha o modelo (4 faixas é o mais leve; 6 faixas separa guitarra e piano, mas é mais pesado) → **Testar meu celular** (baixa o modelo uma vez; use Wi‑Fi).
2. Antes de separar, **feche as outras abas do Chrome** (a falta de memória é o maior risco).
3. Aba **Separar** → botão **+** → escolha a música → Foco (Voz/Instrumental) e Qualidade → **Ouvir prévia (30 s)** → separar a música inteira.
4. No player: volume, silenciar/solo (⋯ em cada faixa), tom e velocidade, Karaokê e Vozes A e B. Ao sair, escolha salvar ou descartar.
5. Aba **Karaokê**: suas gravações salvas.
